# Glossário

| Termo | Significado |
|---|---|
| **KMM** | Kanban Maturity Model. Escala de maturidade de ML0 a ML6. |
| **KMM-S** | Nossa adaptação do KMM para times Scrum. |
| **ML0–ML6** | Níveis: Inconsciente, Focado no time, Orientado ao cliente, Adequado ao propósito, Protegido contra riscos, Líder de mercado, Construído para sobreviver. |
| **Transição / Central** | Práticas que preparam um nível / que o consolidam. |
| **Lead time** | Tempo do início (em andamento) até a conclusão de um item. |
| **P50 / P85** | Metade / 85% dos itens terminam em até esse tempo. |
| **Vazão** (*throughput*) | Itens concluídos por período. |
| **WIP** | Trabalho em andamento. |
| **SLE** | Expectativa de nível de serviço: “85% em até X dias”. |
| **Ponto de compromisso** | Momento em que o time aceita fazer o item. |
| **Classe de serviço** | Regra de prioridade por tipo de demanda (urgente, data fixa, padrão). |
| **Idade do item** (*aging*) | Há quanto tempo um item está em andamento. |
| **Monte Carlo** | Simulação que gera previsão de prazo com probabilidade a partir do histórico. |
| **Service Delivery Manager** | Responsável pelo fluxo de entrega. Papel ausente hoje (L1). |
| **Service Request Manager** | Responsável pela demanda. No Scrum, próximo do PO. |
| **Bloqueador (L1–L4)** | Lacuna que o time não resolve sozinho; depende da gerência. |
| **Pendência de base** | Item sem Sim abaixo do maior nível em que o time tem algum Sim. |
| **Nível a revisar** | Checklist diz ML2+, mas 2 ou mais indicadores estão vermelhos. |
