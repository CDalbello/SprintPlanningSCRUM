# KMM-S · Maturidade de fluxo para times Scrum

Adaptação interna do Kanban Maturity Model (KMM) para diagnosticar times que usam Scrum e mostrar aos gerentes o caminho até a previsibilidade.

**Status:** v0.1 · Discovery concluído (fases 1–4) · Próximo: piloto.
